# CheckUp — Legal pages (GitHub Pages)

Public HTTPS URLs for App Store / Play Console.

## Enable Pages

1. Repo **Settings → Pages**
2. **Build and deployment → Source:** Deploy from a branch
3. Branch: `main` / folder: `/ (root)`
4. Save and wait ~1–2 minutes

## URLs

- https://evandrogrm.github.io/checkup-legal/
- https://evandrogrm.github.io/checkup-legal/privacy-policy.html
- https://evandrogrm.github.io/checkup-legal/terms-of-use.html

## Updating content

Edit HTML here, or copy from the private monorepo `checkup/docs/legal/` and push to `main`.
